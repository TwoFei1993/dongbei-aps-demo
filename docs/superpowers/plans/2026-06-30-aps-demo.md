# 东北特钢 APS 智能排产 Demo 实施计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建基于真实客户数据的东北特钢 APS 智能排产纯前端 Demo，部署到 Vercel，通过链接直接访问。

**Architecture:** Next.js 15.4 静态导出（`output: 'export'`），五个路由共享钢铁灰 AppShell；真实 Excel 数据由 Python 预处理脚本提取为 JSON 后静态导入；ECharts 5 按需加载（动态 import + SSR 禁用）渲染所有图表；Zustand 管理全局筛选状态。

**Tech Stack:** Next.js 15.4 · React 19 · TypeScript strict · Tailwind CSS v4 · shadcn/ui · ECharts 5 + echarts-for-react · Zustand · lucide-react · pnpm · uv + openpyxl/pandas (数据预处理)

- `build_gantt`：读东区/西区72小时作业计划，按炉次逐行生成 GanttTask，stage 从 sheet 名推断
- `build_furnace_model`：基于合理化参数生成加热预测曲线、装炉分组、均热节拍 JSON

export function KpiCard({ title, value, unit, trend, trendUp, children }: KpiCardProps) {
  return (
    <div
      className="rounded-xl p-4"
      style={{ backgroundColor: 'var(--color-card-bg)',
               border: '1px solid var(--color-card-border)',
               boxShadow: '0 1px 4px rgba(37,51,72,0.06)' }}
    >
      <div className="mb-1 text-[11px] font-medium uppercase tracking-wide"
           style={{ color: 'var(--color-text-muted)' }}>
        {title}
      </div>
      <div className="flex items-baseline gap-1">
        <span className="text-2xl font-bold" style={{ color: 'var(--color-text-title)' }}>
          {value}
        </span>
        {unit && <span className="text-sm" style={{ color: 'var(--color-text-muted)' }}>{unit}</span>}

// src/components/scene2/CrossGantt.tsx
'use client'
import { useState } from 'react'
import { ChartWrapper } from '@/components/shared/ChartWrapper'
import { loadGantt } from '@/lib/data-loader'
import type { GanttTask } from '@/types'

const tasks = loadGantt()

const STAGE_COLORS: Record<GanttTask['stage'], string> = {
  casting:  '#4a7cdc',
  heating:  '#f59e0b',
  rolling:  '#10b981',
  finishing: '#8b5cf6',
}

const STAGE_LABELS: Record<GanttTask['stage'], string> = {
  casting:  '连铸',
  heating:  '加热炉',
  rolling:  '轧机',
  finishing: '精整',
}

const equipments = [...new Set(tasks.map((t) => t.equipment))]
const baseTime = new Date('2026-06-21T00:00:00').getTime()
const rangeMs = 72 * 60 * 60 * 1000

export function CrossGantt() {
  const [highlightBatch, setHighlightBatch] = useState<string | null>(null)

  const seriesData = tasks.map((t) => {
    const st = new Date(t.startTime).getTime()
    const et = new Date(t.endTime).getTime()
    const yIdx = equipments.indexOf(t.equipment)
    const dimOpacity = highlightBatch && t.batchId !== highlightBatch ? 0.2 : 1
    return {
      value: [yIdx, st, et, t],
      itemStyle: {
        color: STAGE_COLORS[t.stage],
        opacity: dimOpacity,
        borderRadius: 3,
      },
    }
  })

  const option = {
    tooltip: {
      formatter: (p: { value: [number, number, number, GanttTask] }) => {
        const t = p.value[3]
        return `<b>${t.steelGrade}</b><br/>${t.equipment}<br/>${t.spec}<br/>批次: ${t.batchId}`
      },
    },
    legend: {
      data: Object.entries(STAGE_LABELS).map(([k, v]) => ({ name: v, itemStyle: { color: STAGE_COLORS[k as GanttTask['stage']] } })),
      bottom: 0, textStyle: { fontSize: 10 },
    },
    grid: { top: 10, right: 20, bottom: 40, left: 100 },
    xAxis: {
      type: 'time',
      min: baseTime,
      max: baseTime + rangeMs,
      axisLabel: { formatter: (v: number) => {
        const d = new Date(v)
        return `${d.getMonth()+1}/${d.getDate()} ${d.getHours()}:00`
      }, fontSize: 10 },
    },
    yAxis: {
      type: 'category',
      data: equipments,
      axisLabel: { fontSize: 10 },
    },
    series: [{
      type: 'custom',
      renderItem: (_: unknown, api: {
        value: (idx: number) => number
        coord: (arr: [number, number]) => [number, number]
        size: (arr: [number, number]) => [number, number]
        style: (opts?: Record<string, unknown>) => Record<string, unknown>
      }) => {
        const yIdx = api.value(0)
        const start = api.coord([api.value(1), yIdx])
        const end = api.coord([api.value(2), yIdx])
        const height = api.size([0, 1])[1] * 0.6
        return {
          type: 'rect',
          shape: {
            x: start[0], y: start[1] - height / 2,
            width: end[0] - start[0], height,
          },
          style: api.style(),
        }
      },
      data: seriesData,
      encode: { x: [1, 2], y: 0 },
    }],
  }

  return (
    <div className="space-y-2">
      <p className="text-[11px]" style={{ color: 'var(--color-text-muted)' }}>
        点击色块高亮同批次 · 数据来源：2026年6月21~23日东区/西区72小时作业计划
      </p>
      <div onClick={(e) => {
        const target = e.target as SVGElement
        if (target.tagName !== 'path' && target.tagName !== 'rect') { setHighlightBatch(null) }
      }}>
        <ChartWrapper
          option={option}
          height={360}
        />
      </div>
    </div>
  )
}

### 修订 1：CrossGantt 点击高亮 — 改用 onEvents（原 Task 8 Step 1 替换）

ECharts 默认使用 Canvas 渲染，DOM 事件监听 SVG 标签无效。
**正确做法：** 通过 `echarts-for-react` 的 `onEvents` prop 绑定原生 click 事件。

**A. ChartWrapper.tsx 增加 onEvents 可选 prop：**

```tsx
// src/components/shared/ChartWrapper.tsx
// 在 props interface 中添加：
interface ChartWrapperProps {
  option: Record<string, unknown>
  height?: number
  onEvents?: Record<string, (params: unknown) => void>
}
// 传递给 ReactECharts：
<ReactECharts option={option} style={{ height }} onEvents={onEvents} />
```

**B. CrossGantt.tsx 使用 onEvents：**

```tsx
// 替换原来的 div onClick 方案：
const events = {
  click: (params: { data?: { value?: [number, number, number, GanttTask] } }) => {
    const batchId = params.data?.value?.[3]?.batchId ?? null
    setHighlightBatch((prev) => (prev === batchId ? null : batchId))
  },
}

// JSX 中去掉外层 div onClick，直接：
<ChartWrapper option={option} height={360} onEvents={events} />
```

**验证：** 点击甘特图色块 → `highlightBatch` 更新 → 同批次色块不透明、其余 opacity=0.2。
